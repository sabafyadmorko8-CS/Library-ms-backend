🗄️ MySQL Database Setup

Convert your Library Management System from SQLite to MySQL

1Prerequisites Check

Make sure MySQL is running on your system (XAMPP, WAMP, or standalone MySQL)

2Create Database

Create the MySQL database for your Library Management System

Database Configuration:
• Host: 127.0.0.1
• Port: 3306
• Database: Library_ms
• Username: root
• Password: (empty)

3Run Migrations

Create all the database tables (users, books, borrows, etc.)

Alternative: Run this command in your terminal:
php artisan config:clear && php artisan migrate:fresh

4Create Demo Data

Populate the database with sample users and books

5Verify Setup

Test that everything is working correctly

🎉 Success! Next Steps

Your MySQL database is ready!

Access Your App:
• React Frontend: http://localhost:3000
• Laravel API: http://127.0.0.1:8000/api/test
• phpMyAdmin: http://localhost/phpmyadmin
